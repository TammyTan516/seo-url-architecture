# 可复制表头模板

下面每行可以直接复制到飞书多维表格第一行，再手动设置字段类型和下拉选项。

## URL资产主表

```csv
Page ID,Page Name,Canonical URL,URL Path,Canonical Domain,Language,Page Type,Page Group,Parent Page ID,Status,Indexable,Sitemap Included,Canonical Target,Hreflang Pair Page ID,Owner,Tech Owner,Priority,Source,Last Updated,Notes
```

## SEO配置表

```csv
SEO Config ID,Page ID,Canonical URL,SEO URL,SEO Title,Meta Description,Primary Keyword,Secondary Keywords,H1,LLM Summary,Schema Type,OG Title,OG Description,SEO Status,Config Owner,Last SEO Updated,Notes
```

## 关键词地图表

```csv
Keyword ID,Keyword,Language,Search Intent,Keyword Cluster,Target Page ID,Target URL,Priority,Content Type,Status,Notes
```

## 技术SEO检查表

```csv
Check ID,Page ID,URL,Check Date,HTTP Status,Final URL,Title Check,Meta Check,H1 Check,Canonical Check,Sitemap Check,Robots Check,Hreflang Check,Index Status,Issue Level,Issue Summary,Fix Owner,Fix Status,Last Checked By
```

## 重定向与URL变更表

```csv
Redirect ID,Old URL,New URL,Old Page ID,New Page ID,Redirect Type,Reason,Status,Requested By,Tech Owner,Requested Date,Verified Date,Notes
```

## 内容页面需求表

```csv
Request ID,Request Type,Topic,Primary Keyword,Target Page Type,Target Language,Draft Doc URL,Target URL Path,Related Page ID,Status,SEO Config ID,Published URL,Owner,Notes
```

## 配置字典

```csv
Config Key,Config Value,Applies To,Owner,Last Updated,Notes
```
